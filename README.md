# AI Document Q&A Assistant

A Generative AI-powered application that allows users to upload documents and ask questions about their content.

The project uses Retrieval-Augmented Generation (RAG) to retrieve relevant information from documents and an LLM to generate context-aware answers.

## Overview

The AI Document Q&A Assistant is designed to simplify information retrieval from documents through natural-language interaction.

Users will be able to upload a document, ask questions about its content, and receive answers based on the information available in the uploaded document.

## Key Features

- Document upload and processing
- Text extraction and preprocessing
- Text chunking
- Embedding generation
- Semantic document retrieval
- FAISS-based vector search
- Retrieval-Augmented Generation (RAG)
- Generative AI-based question answering
- Interactive Streamlit interface

## Technology Stack

- Python
- Generative AI
- Retrieval-Augmented Generation (RAG)
- Large Language Models (LLM)
- Streamlit
- FAISS
